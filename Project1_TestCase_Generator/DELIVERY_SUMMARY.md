## 🚀 How to Get Started (3 Steps)

### Step 1: Open the Application
```bash
# Option A: Direct open
open index.html

# Option B: Local server (recommended)
python3 -m http.server 8000
# Then visit: http://localhost:8000
```

### Step 2: Configure RICE-POT (Optional)
All components are pre-filled with working defaults. You can:
- Change system name to your API
- Update team contact names
- Adjust sprint duration
- Customize other settings

Or just click **Generate** with defaults.

### Step 3: Export Your Test Plan
Click **Export** to download comprehensive test plan as Markdown.
