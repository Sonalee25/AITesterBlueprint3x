### Feature 2: RICE-POT Framework
7 components ensuring deterministic, hallucination-free output:
- **R**ole — QA expertise level
- **I**nstructions — 12 sections + validation rules
- **C**ontext — System-specific details
- **E**xample — Format anchors
- **P**arameters — Validation constraints
- **O**utput — Exact Markdown spec
- **T**one — Professional, formal style

**See:** [prompt.md](prompt.md) and [SKILLS.md](SKILLS.md) → "RICE-POT Framework Mastery"

### Feature 3: Test Case Database
Pre-built test scenarios for every endpoint:
- **6 endpoints** covered
- **5-8 test cases per endpoint**
- **Multiple test types** (Functional, Security, Performance, etc.)
- **Structured JSON format** ready for automation

**See:** [README.md](README.md) → "Test Cases Database" section and [app.js](app.js) → `TEST_CASES_DB` object

### Feature 4: Multi-Format Export
- **Markdown** — For documentation & version control
- **Print/PDF** — Via browser print dialog
- **Copy-paste** — Direct to Confluence, JIRA, etc.

**See:** [README.md](README.md) → "Step 3: Review & Export"

### Feature 5: Real-Time Preview
See test plan sections update instantly as you configure RICE-POT components.

**See:** [app.js](app.js) → Event handlers and preview update functions

### Feature 6: Responsive Design
Works seamlessly on desktop, tablet, and mobile.

**See:** [styles.css](styles.css) → Media queries and responsive grid
